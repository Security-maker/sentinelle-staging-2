# Sentinelle Pro V5.11.3 — TEST SAFE · Simple Flow

Version de test ergonomique du portail Agent.

## Principe

- Une carte mission compacte
- Une action principale contextuelle
- Un seul point d’entrée pour alimenter la main courante
- 5 catégories seulement : Personnel, Accès / Visiteurs, Ronde / Surveillance, Livraisons / Objets, Incident / Autre
- Une situation → un texte professionnel déjà rédigé → validation / modification / photo
- Ronde visuelle proposée uniquement si elle est configurée sur le site
- Aquila reste contextuel et n’apparaît que lorsqu’un accès valide existe
- Timeline limitée aux derniers événements pour ne pas surcharger l’accueil

## TEST SAFE

Les écritures métier restent en shadow local dans ce repo de test. Aucun push QG production ni e-mail client n’est envoyé.
