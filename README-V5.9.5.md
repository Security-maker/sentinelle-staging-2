# Sentinelle Pro V5.9.5 — Client Premium

Cette version modifie uniquement l’interface client. Les interfaces Agent et QG restent inchangées.

## Nouveautés
- Suppression des points de fin dans les titres et sous-titres du portail client.
- Accès direct à la dernière main courante disponible depuis le tableau de bord client, avec ouverture et téléchargement du PDF.
- Logo client dédié dérivé du logo Azzera Protect fourni, en conservant exactement sa teinte bleue #64D0FF.
- Icônes PWA client 180, 192 et 512 px régénérées avec la teinte officielle du logo.
- Palette client harmonisée autour de la teinte Azzera Protect, avec marine profond pour conserver une interface B2B sobre et lisible.
- Cache Service Worker client porté en V5.9.5.

## Déploiement
Déposer le contenu du ZIP UPDATE à la racine du dépôt GitHub Pages, en conservant le dossier `assets`.

Aucune migration SQL ni modification Edge Function n’est nécessaire.
